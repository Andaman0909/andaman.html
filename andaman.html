MODULE 1
INTRODUCTION TO COMPUTING

Understanding Computers and Information

Lesson 1: Information Systems

An information system is a combination of people, procedures, data, and technology used to collect, process, store, and share information.

Components of an Information System

  1. Hardware: Physical computer equipment.
    2. Computer Hardware

    Computer Hardware Components

  2. Software: Programs used to perform tasks.
  3. Data: Facts that can be processed into information.
  4. People: Users who operate the system.
  5. Procedures: Rules and instructions for using the system.
  6. Networks: Connections that allow devices to exchange information.

Examples of Information Systems

  • School enrollment systems
  • Hospital information systems
  • Banking systems
  • Inventory systems
  • Online shopping systems

Example: A school information system stores student names, grades, attendance, and enrollment records.


Lesson 2: Database and MySQL

A database is an organized collection of related data. A database management system helps users create, organize, retrieve, and update that data.

MySQL is a relational database management system that uses SQL to work with data stored in tables.

Lesson 3: Entities, Attributes and Relationships

An entity is a person, place, object, event, or concept about which data is stored.

Two Common Entity Categories

  • Strong Entity: Has its own key to identify its records.
  • Weak Entity: Depends on another entity for identification.

Examples of Entities

  • Student
  • Teacher
  • School
  • Book
  • Product
  • Transaction

Types of Attributes

  • Simple: Cannot be divided into smaller meaningful parts.
  • Composite: Can be divided into smaller parts.
  • Single-valued: Has one value per entity.
  • Multivalued: Can have several values.
  • Derived: Calculated from other information.
  • Key Attribute: Helps uniquely identify a record.

Degree of a Relationship Set

Degree Description
UnaryInvolves one entity type.
BinaryInvolves two entity types.
TernaryInvolves three entity types.
N-aryInvolves more than three entity types.

Example: A student enrolls in a subject. Student and Subject form a binary relationship.

Lesson 4: Computer Memory and Storage

Computer memory holds data and instructions needed for processing. Storage devices keep files and information for future use.

Types of Primary Memory

  • RAM: Temporary working memory. Its contents are generally lost when power is turned off.
  • ROM: Memory that retains important instructions without power.

Types of Secondary Memory

  • HDD: Uses rotating magnetic disks.
  • SSD: Uses flash memory without moving mechanical parts.
  • USB Flash Drive: Portable data storage.
  • Memory Card: Used in many portable devices.
  • Optical Disc: Includes CD, DVD, and Blu-ray.
  • Magnetic Tape: Often used for backups and archives.

Magnetic Tape

Magnetic tape stores data magnetically on a long strip of tape. It is useful for long-term backup and storing large amounts of information.

Storage Measurements

Unit Meaning
BitA binary digit: 0 or 1.
Byte8 bits.
KBApproximately 1,000 bytes.
MBApproximately 1 million bytes.
GBApproximately 1 billion bytes.
TBApproximately 1 trillion bytes.
PBApproximately 1 quadrillion bytes.

Binary units differ: 1 KiB = 1,024 bytes.

Basic Hardware Components

  • Input Devices: Enter data.
  • CPU: Executes instructions.
  • Memory: Holds working data.
  • Storage: Keeps files and programs.
  • Output Devices: Present results.
  • Motherboard: Connects components.

Parts of the System Unit

  1. Motherboard
  2. Central Processing Unit (CPU)
  3. Random Access Memory (RAM)
  4. Storage drive
  5. Power Supply Unit (PSU)
  6. Cooling fans or heat sink
  7. Expansion cards
  8. Computer case

Types of Monitors

  • CRT: Older, bulky display technology.
  • LCD: Uses liquid crystals.
  • LED: Commonly an LCD monitor with LED backlighting.
  • OLED: Uses self-emitting pixels.
  • Touchscreen: Supports interaction by touch.

Output Devices

  • Monitor
  • Printer
  • Speakers
  • Headphones
  • Projector
  • Plotter

Connecting Computers and Applying Digital Skills

Lesson 1: Data Communication

Data communication is the exchange of data between devices through a transmission medium.

Basic Components of Data Communication

  1. Sender: Sends the data.
  2. Receiver: Receives the data.
  3. Message: The information being sent.
  4. Transmission Medium: The path through which data travels.
  5. Protocol: Rules that control communication.

Popular Forms of Data

  • Text: Letters, words, and characters.
  • Numbers: Numeric values.
  • Images: Photos, drawings, and graphics.
  • Audio: Speech, music, and sound.
  • Video: Moving visual images, often with sound.

Types of Networks

Network Meaning
PANPersonal Area Network.
LANLocal Area Network.
WLANWireless Local Area Network.
MANMetropolitan Area Network.
WANWide Area Network.

Internet and World Wide Web

The Internet is a worldwide network connecting computer networks. It allows users to communicate and share information.

The World Wide Web (WWW) is a collection of linked web pages and resources accessed through the Internet using a web browser.

Examples of Internet Services

  • Email
  • Social networking
  • Online learning
  • Video conferencing
  • Cloud storage
  • Web browsing
